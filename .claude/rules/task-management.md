# タスク管理ルール

## タスクステータスの定義

| ステータス | 意味 | 条件 |
|-----------|------|------|
| 🔵 Todo | 未着手 | 作業開始前 |
| 🟡 In Progress | 作業中 | 実装中またはセットアップ中 |
| 🟢 Done | 完了 | **コード実装 + バックエンドセットアップ + 動作確認** が全て完了 |
| ⏸️ Blocked | ブロック | 依存タスクや外部要因で停止中 |

## 完了条件チェックリスト

タスクを「Done」にする前に確認：

### コード実装
- [ ] 必要なファイルが全て作成されている
- [ ] インポートエラーがない
- [ ] TypeScriptエラーがない

### バックエンド設定
- [ ] 必要なSupabaseテーブルが作成されている
- [ ] RLSポリシーが設定されている
- [ ] 環境変数（.env）が設定されている
- [ ] APIキー（OpenAI等）が有効である

### 動作確認
- [ ] アプリが起動する
- [ ] 該当機能が動作する（エラーなし）
- [ ] 認証フローが正常に動作する（認証関連の場合）

## タスクファイル更新

タスク完了時に更新する箇所：

1. `tasks/XXX-task-name.md` のステータス
2. `tasks/README.md` の一覧表
3. 完了条件のチェックボックス
