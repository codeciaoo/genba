# 日報テンプレート仕様

## 目的

一人親方が現場終わりに作成する作業記録。
請求書作成の元データとなり、「言った言わない」防止にも使う。

## レイアウト構成

```
+--------------------------------------------------+
|  [屋号/ロゴ]                  作 業 日 報           |
+--------------------------------------------------+
|  日付: 2026年1月17日（金）                         |
|  現場名: 田中邸                                    |
|  住所: 東京都○○区...                              |
+--------------------------------------------------+
|  【作業内容】                                      |
|                                                   |
|  ✅ エアコン設置（リビング 14畳用）                 |
|  ✅ 配管工事 2m                                   |
|  ✅ 試運転確認                                    |
|                                                   |
+--------------------------------------------------+
|  【使用材料】                                      |
|                                                   |
|  ・冷媒配管 2m                                    |
|  ・ドレンホース 3m                                 |
|  ・スリーブ 1個                                   |
|                                                   |
+--------------------------------------------------+
|  【追加作業・変更】                                |
|                                                   |
|  ・配管経路変更のため追加2m                        |
|  （お客様了承済み）                                |
|                                                   |
+--------------------------------------------------+
|  【備考・申し送り】                                |
|                                                   |
|  ・次回：室外機カバー取付予定                       |
|  ・駐車場: 玄関前OK                               |
|                                                   |
+--------------------------------------------------+
|  作業者: 山田太郎                                  |
|  作業時間: 9:00 - 12:30（3.5h）                   |
+--------------------------------------------------+
```

## デザイン仕様

### ヘッダー
- 背景: `--genba-navy-900`
- 文字: 白
- 高さ: 60px

### セクション見出し【】
- 背景: `--genba-gray-100`
- 文字: `--genba-navy-700`
- パディング: 8px 12px

### チェックマーク
- 色: `--genba-success`
- アイコン: ✅ または ☑

### 追加作業セクション
- 左ボーダー: 4px solid `--genba-warning`
- 背景: 薄いオレンジ `rgba(199, 119, 0, 0.05)`

## PDF出力仕様

- サイズ: A4縦（または画面表示用にスマホ幅）
- マージン: 15mm
- ファイル名例: `日報_田中邸_20260117.pdf`

## データ構造（JSON）

```json
{
  "report_date": "2026-01-17",
  "site": {
    "name": "田中邸",
    "address": "東京都○○区..."
  },
  "work_items": [
    {
      "description": "エアコン設置",
      "details": "リビング 14畳用",
      "completed": true
    },
    {
      "description": "配管工事",
      "details": "2m",
      "completed": true
    },
    {
      "description": "試運転確認",
      "completed": true
    }
  ],
  "materials": [
    {"name": "冷媒配管", "quantity": "2m"},
    {"name": "ドレンホース", "quantity": "3m"},
    {"name": "スリーブ", "quantity": "1個"}
  ],
  "additional_work": [
    {
      "description": "配管経路変更のため追加2m",
      "approved": true,
      "approval_note": "お客様了承済み"
    }
  ],
  "notes": [
    "次回：室外機カバー取付予定",
    "駐車場: 玄関前OK"
  ],
  "worker": "山田太郎",
  "work_hours": {
    "start": "09:00",
    "end": "12:30",
    "total_hours": 3.5
  }
}
```

## 音声入力からの変換例

**音声入力**:
「今日の現場、田中邸。エアコン設置完了。配管2メートル追加。次回カバーつける」

**抽出データ**:
```json
{
  "site_hint": "田中邸",
  "work_items": [
    {"description": "エアコン設置", "completed": true}
  ],
  "additional_work": [
    {"description": "配管追加", "quantity": "2m"}
  ],
  "notes": [
    "次回カバー取付"
  ]
}
```

## 日報から請求書への連携

日報の作業内容は請求書の明細に自動転記可能:

| 日報の項目 | 請求書の項目 |
|-----------|-------------|
| エアコン設置 | エアコン設置工事 |
| 配管工事 2m | 配管工事 × 2m |
| 追加作業 | 追加工事費 |

※品目テンプレート（辞書）で単価を自動補完
