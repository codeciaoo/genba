# 請求書テンプレート仕様

## インボイス制度対応要件

適格請求書（インボイス）に必要な記載事項:

1. **発行者の氏名・名称**
2. **登録番号** (T + 13桁の数字)
3. **取引年月日**
4. **取引内容**
5. **税率ごとの対価の額および適用税率**
6. **税率ごとの消費税額**
7. **交付を受ける事業者の氏名・名称**

## フォント・色指定

### ヘッダー（屋号）
- フォント: Noto Sans JP Bold
- サイズ: 20px
- 色: `--genba-navy-900`

### タイトル「請求書」
- フォント: Noto Sans JP Bold
- サイズ: 28px
- 色: `--genba-navy-900`

### ご請求金額
- フォント: Noto Sans JP Bold
- サイズ: 24px
- 色: `--genba-teal-700`
- 背景: `--genba-teal-100` (薄くハイライト)

### 明細テーブル
- ヘッダー背景: `--genba-gray-100`
- ボーダー: 1px solid `--genba-gray-300`
- 行高: 40px

### 合計行
- 背景: `--genba-teal-100`
- 文字: Bold

## PDF出力仕様

- サイズ: A4縦
- マージン: 上下左右 20mm
- 日本語フォント埋め込み必須
- ファイル名例: `請求書_田中様_20260117.pdf`

## 音声入力からの変換例

**音声入力**:
「今日の現場、田中邸。エアコン設置完了。配管2メートル追加。出張費込みで」

**抽出データ**:
```json
{
  "client_hint": "田中",
  "items": [
    {"description": "エアコン設置", "quantity": 1, "unit": "式"},
    {"description": "配管工事", "quantity": 2, "unit": "m"},
    {"description": "出張費", "quantity": 1, "unit": "回"}
  ]
}
```

※単価はテンプレート（品目辞書）から自動補完
