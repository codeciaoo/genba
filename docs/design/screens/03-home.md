## インタラクション

### カードタップ

```
1. カードにリップルエフェクト
2. 200ms後に下書き確認/日報詳細画面へ遷移
   - 下書き → /draft/[id]
   - 確定 → /report/[id]
```

### 音声ボタンタップ

```
1. ボタンが少し縮小（フィードバック）
2. 軽い触覚フィードバック（Haptics）
3. 音声入力画面へ遷移 /voice
```

### プルトゥリフレッシュ

```
1. 画面を下に引っ張る
2. スピナー表示
3. 同期処理実行
4. 完了後リスト更新
```

### スワイプ操作（カード）

```
左スワイプ:
- 「削除」ボタン表示（赤背景）
- 確認ダイアログ後に削除

右スワイプ:
- 「日報作成」ボタン表示（緑背景）
- タップで日報プレビュー画面へ
```

## アニメーション

### カード表示

```
初期表示時:
- 各カードが下からスライドイン
- 0.1秒ずつディレイ（stagger）
- opacity: 0 → 1, translateY: 20px → 0
```

### 音声ボタン

```
待機時:
- 軽い呼吸アニメーション（scale: 1 ↔ 1.02）
- 2秒周期

タップ時:
- scale: 1 → 0.95 → 1
- 100ms
```

### 同期完了時

```
1. オフラインバナーが上にスライドアウト
2. 「同期完了」トースト表示（2秒で消える）
```

## 実装メモ

```typescript
// 今日の作業記録を取得
const useTodayRecords = () => {
  const today = new Date().toISOString().split('T')[0];
  return useQuery(
    database.get<WorkRecord>('work_records')
      .query(
        Q.where('recorded_at', Q.gte(startOfDay(today))),
        Q.sortBy('recorded_at', Q.desc)
      )
  );
};

// 挨拶メッセージ
const getGreeting = () => {
  const hour = new Date().getHours();
  if (hour < 12) return 'おはようございます';
  if (hour < 18) return 'こんにちは';
  return 'おつかれさまです';
};
```
