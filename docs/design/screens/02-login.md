## インタラクション

### 電話番号入力

```
1. ユーザーが数字を入力
2. 自動でハイフン挿入（3桁-4桁-4桁）
3. 11桁入力完了でボタン有効化
4. ボタンタップ → SMS送信API呼び出し
5. 成功 → OTP入力画面へスライド遷移
```

### OTP入力

```
1. 最初のボックスに自動フォーカス
2. 数字入力 → 次のボックスへ自動移動
3. 6桁入力完了 → 自動で認証API呼び出し
4. 成功 → ホーム画面へ遷移
5. 失敗 → エラー表示、入力クリア
```

## アニメーション

### 画面遷移

| 遷移 | アニメーション |
|------|--------------|
| スプラッシュ → ログイン | フェードイン 300ms |
| 電話番号 → OTP | 左スライド 250ms |
| OTP → ホーム | フェードアウト + ズーム 300ms |

### OTP入力完了

```
1. 6桁入力完了
2. 全ボックスが緑に変化
3. チェックマークがポップイン
4. 0.3秒後にホーム画面へ遷移
```

### エラー時

```
1. ボックスが赤に変化
2. 横に小さく振動（shake animation）
3. 0.5秒後に入力クリア
4. 最初のボックスにフォーカス
```
