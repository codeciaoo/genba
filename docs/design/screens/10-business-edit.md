## インタラクション

### 住所自動入力

```
1. 郵便番号を7桁入力
2. 「住所を自動入力」ボタンが有効化
3. タップ
4. ローディング表示（ボタン内スピナー）
5. 郵便番号API呼び出し
6. 成功 → 住所フィールドに自動入力
7. 失敗 → 「住所を取得できませんでした」トースト
```

### 保存

```
1. いずれかのフィールドを変更
2. 「保存」ボタンが有効化（色変化）
3. タップ
4. バリデーション実行
5. 成功 → 保存処理 → 「保存しました」トースト → 自動で戻る
6. 失敗 → エラー表示
```

### 戻る（変更あり）

```
1. 「← 戻る」をタップ
2. 未保存の変更がある場合、確認ダイアログ
   「変更を保存せずに戻りますか？」
3. 「破棄して戻る」で前画面へ
4. 「キャンセル」でダイアログを閉じる
```

## 状態表示

### 保存ボタン

| 状態 | 表示 |
|------|------|
| 変更なし | 「保存」グレー、disabled |
| 変更あり | 「保存」`--genba-teal-700` |
| 保存中 | スピナー + 「保存中...」 |
| エラーあり | 「保存」赤、タップでエラーにスクロール |

### 自動保存（オプション）

```
- フィールドからフォーカスが外れると自動保存
- 「保存しました」の小さなフィードバック
- エラー時は自動保存しない
```

## アニメーション

### 画面表示

```
0ms   : 説明テキストがフェードイン
100ms : フィールドが順にフェードイン（stagger 30ms）
```

### エラー表示

```
1. フィールドが赤ボーダーに変化
2. エラーメッセージがスライドダウン
3. 軽い振動（shake）
```

### 保存成功

```
1. 「保存しました ✓」トーストが画面上部からスライドイン
2. 1.5秒後にフェードアウト
3. 同時に前画面へ戻る遷移開始
```

## 実装メモ

```typescript
// 郵便番号から住所を取得
const fetchAddressByPostalCode = async (postalCode: string) => {
  const response = await fetch(
    `https://zipcloud.ibsnet.co.jp/api/search?zipcode=${postalCode.replace('-', '')}`
  );
  const data = await response.json();

  if (data.results && data.results.length > 0) {
    const result = data.results[0];
    return `${result.address1}${result.address2}${result.address3}`;
  }
  throw new Error('住所が見つかりません');
};

// インボイス登録番号フォーマット
const formatInvoiceNumber = (value: string) => {
  // 数字のみ抽出
  const digits = value.replace(/\D/g, '').slice(0, 13);
  return digits.length > 0 ? `T${digits}` : '';
};

// 電話番号フォーマット
const formatPhoneNumber = (value: string) => {
  const digits = value.replace(/\D/g, '');
  if (digits.length <= 3) return digits;
  if (digits.length <= 7) return `${digits.slice(0, 3)}-${digits.slice(3)}`;
  return `${digits.slice(0, 3)}-${digits.slice(3, 7)}-${digits.slice(7, 11)}`;
};
```
