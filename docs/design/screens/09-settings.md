|------|-------|

| お問い合わせ | メールアプリ起動 |

## インタラクション

### 設定項目タップ

```
1. 行にリップルエフェクト
2. 150ms後に遷移先画面へプッシュ
```

### プロフィールカードタップ

```
1. 事業者情報画面へ遷移
```

### データ同期タップ

```
1. 同期詳細画面へ遷移
2. 手動同期ボタンあり
3. 同期履歴表示
```

### お問い合わせタップ

```
1. メールアプリ起動
2. 宛先: support@genba-gear.app
3. 件名: 「GENBA GEAR お問い合わせ」
4. 本文にアプリバージョンとデバイス情報を自動挿入
```

### ログアウト

```
1. 「ログアウト」をタップ
2. 確認ダイアログ表示
   「ログアウトしますか？未同期のデータはこの端末に残ります。」
3. 「ログアウト」で実行
4. ログイン画面へ遷移
```

## 状態表示

### 同期状態

| 状態 | 表示 |
|------|------|
| 同期済み | 「最終同期: X分前」緑テキスト |
| 同期中 | 「🔄 同期中...」アイコン回転 |
| 未同期あり | 「⚠ X件の未同期データ」オレンジ |
| オフライン | 「オフライン」グレー |

### 事業者情報未設定

| 状態 | 表示 |
|------|------|
| 未設定項目あり | サブラベルに「⚠ 設定が必要です」オレンジ |

## アニメーション

### 画面表示

```
0ms   : プロフィールカードがフェードイン
100ms : 設定項目が順にフェードイン（stagger 30ms）
```

### 同期中

```
- 🔄アイコンが回転（1秒/周）
- サブラベルが「同期中...」にフェード
```

### ログアウト

```
1. ダイアログで「ログアウト」をタップ
2. 画面全体がフェードアウト
3. ログイン画面へ
```

## 実装メモ

```typescript
// お問い合わせメール
const openSupportEmail = async () => {
  const deviceInfo = `
    アプリバージョン: ${Constants.expoConfig?.version}
    OS: ${Platform.OS} ${Platform.Version}
    デバイス: ${Device.modelName}
  `;

  const url = `mailto:support@genba-gear.app?subject=${encodeURIComponent(
    'GENBA GEAR お問い合わせ'
  )}&body=${encodeURIComponent(deviceInfo)}`;

  await Linking.openURL(url);
};

// 同期状態の表示
const formatLastSyncTime = (lastSync: Date | null) => {
  if (!lastSync) return 'まだ同期していません';

  const diffMinutes = differenceInMinutes(new Date(), lastSync);
  if (diffMinutes < 1) return 'たった今';
  if (diffMinutes < 60) return `${diffMinutes}分前`;

  const diffHours = differenceInHours(new Date(), lastSync);
  if (diffHours < 24) return `${diffHours}時間前`;

  return format(lastSync, 'M/d HH:mm');
};
```
