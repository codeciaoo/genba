## インタラクション

### PDF出力

```
1. 「PDF」ボタンをタップ
2. ローディング表示（ボタン内スピナー）
3. PDF生成（クライアント側 expo-print）
4. シェアシート表示
```

### 共有

```
1. 「共有」ボタンをタップ
2. 共有オプション選択モーダル
   - PDF形式で共有
   - テキストで共有
   - 画像で共有
3. 選択後、シェアシート表示
```

### 住所タップ

```
1. 住所エリアをタップ
2. 確認ダイアログ「地図アプリで開きますか？」
3. 「開く」で地図アプリ起動（Google Maps / Apple Maps）
```

### 請求書作成リンク

```
1. リンクをタップ
2. 請求書編集画面へ遷移
3. 日報の内容が自動で明細に転記される
```

### メニュー > 削除

```
1. 「削除」をタップ
2. 確認ダイアログ
   「この日報を削除しますか？この操作は取り消せません。」
3. 「削除する」で削除実行
4. 日報一覧画面へ戻る
5. 「日報を削除しました」トースト表示
```

## アニメーション

### 画面表示

```
0ms   : 背景表示
100ms : ステータスバッジがポップイン
150ms : 日付がフェードイン
200ms : 現場情報がフェードイン
250ms : 各セクションが順にフェードイン（stagger 50ms）
400ms : フッターボタンが下からスライドイン
```

### 削除

```
1. ダイアログで「削除する」をタップ
2. 画面全体が左へスライドアウト
3. 日報一覧画面へ
```

## 実装メモ

```typescript
// テキスト形式で共有用のフォーマット
const formatReportAsText = (report: DailyReport): string => {
  return `
【作業日報】
日付: ${formatDate(report.date)}
現場: ${report.siteName}

■ 作業内容
${report.workItems.map(item => `・${item.description}`).join('\n')}

■ 備考
${report.notes.join('\n')}

作業者: ${report.workerName}
作業時間: ${report.workHours}
  `.trim();
};

// 地図アプリで開く
const openInMaps = async (address: string) => {
  const url = Platform.select({
    ios: `maps:?q=${encodeURIComponent(address)}`,
    android: `geo:0,0?q=${encodeURIComponent(address)}`,
  });
  await Linking.openURL(url);
};
```
