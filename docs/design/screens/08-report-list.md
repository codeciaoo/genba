## インタラクション

### 検索

```
1. 検索バーをタップ
2. キーボードが表示
3. 入力開始
4. 300msデバウンス後に検索実行
5. 結果をリアルタイム表示
6. ×ボタンでクリア
```

### フィルター

```
1. チップをタップ
2. 選択状態がトグル
3. 複数選択不可（単一選択）
4. リストが即座にフィルタリング
```

### カード

```
1. カードをタップ
2. リップルエフェクト
3. 日報詳細画面へ遷移
```

### カレンダー

```
1. 日付をタップ
2. その日の日報リストを下部に表示
3. 左右スワイプで月移動
4. 日報ありの日のみタップ可能（ドット付き）
```

### プルトゥリフレッシュ

```
1. 画面を下に引っ張る
2. ローディングスピナー表示
3. 同期処理実行
4. リスト更新
```

### 無限スクロール

```
- リストビューで下端に到達すると古い日報を追加読み込み
- 月ごとにグループ化
- 最大1年分をキャッシュ
```

## アニメーション

### リスト表示

```
初期表示時:
- 各カードが下からスライドイン
- 0.05秒ずつディレイ（stagger）
- 最大10件までアニメーション
```

### ビュー切替

```
リスト → カレンダー:
- リストが上へスライドアウト
- カレンダーが下からスライドイン
- 200ms

カレンダー → リスト:
- カレンダーが下へスライドアウト
- リストが上からスライドイン
- 200ms
```

### カレンダー月移動

```
左へスワイプ（次月）:
- 現在の月が左へスライドアウト
- 次の月が右からスライドイン

右へスワイプ（前月）:
- 現在の月が右へスライドアウト
- 前の月が左からスライドイン
```

## 実装メモ

```typescript
// 月ごとにグループ化
const groupReportsByMonth = (reports: DailyReport[]) => {
  return reports.reduce((acc, report) => {
    const monthKey = format(report.date, 'yyyy年M月');
    if (!acc[monthKey]) {
      acc[monthKey] = [];
    }
    acc[monthKey].push(report);
    return acc;
  }, {} as Record<string, DailyReport[]>);
};

// 検索クエリ
const searchReports = (query: string, filter: FilterType) => {
  return database.get<DailyReport>('daily_reports')
    .query(
      Q.or(
        Q.where('site_name', Q.like(`%${query}%`)),
        Q.where('work_items', Q.like(`%${query}%`))
      ),
      filter !== 'all' && Q.where('status', filter),
      Q.sortBy('report_date', Q.desc)
    );
};
```
