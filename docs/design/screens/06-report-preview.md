## インタラクション

### ピンチズーム

```
- プレビューエリアでピンチイン/アウト可能
- 最小: 0.5x、最大: 2.0x
- ダブルタップでリセット
```

### 確定

```
1. 「この内容で確定」をタップ
2. 確認ダイアログ表示
   「この日報を確定しますか？確定後は編集できません。」
3. 「確定する」で処理
4. ローディング表示
5. 完了後、日報詳細画面へ遷移
6. 「日報を確定しました」トースト表示
```

### 編集

```
1. 「編集」をタップ
2. 下書き確認画面へ戻る（遷移アニメーション: 右へスライド）
```

### PDF出力

```
1. 「PDF」をタップ
2. PDF生成処理（透かしなし版）
3. シェアシート表示
   - AirDrop
   - ファイルに保存
   - メールで送信
   - LINEで送信
```

## アニメーション

### 画面表示

```
0ms   : 背景表示
100ms : 日報カードが下からスライドイン + フェードイン
300ms : 透かしがフェードイン
400ms : フッターボタンが下からスライドイン
```

### 確定成功

```
1. 透かしがフェードアウト
2. カード全体に緑のチェックマークがポップイン
3. 0.5秒後に日報詳細画面へ遷移
```

## 実装メモ

```typescript
// 日報HTMLを生成（PDF用）
const generateReportHtml = (report: DailyReport): string => {
  // references/daily-report-template.md のレイアウトを使用
  return `
    <!DOCTYPE html>
    <html>
    <head>
      <style>
        /* 日報スタイル */
      </style>
    </head>
    <body>
      ${renderReportContent(report)}
    </body>
    </html>
  `;
};

// PDF出力
const exportPdf = async (report: DailyReport) => {
  const html = generateReportHtml(report);
  const { uri } = await Print.printToFileAsync({ html });
  await Sharing.shareAsync(uri, {
    mimeType: 'application/pdf',
    dialogTitle: `日報_${report.siteName}_${formatDate(report.date)}`,
  });
};
```
