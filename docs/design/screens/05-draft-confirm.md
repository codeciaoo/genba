## インタラクション

### 現場名選択

```
1. 入力欄をタップ
2. 既存現場のドロップダウンが開く
3. 入力開始で絞り込み
4. 候補をタップで選択
5. 「新しい現場を登録」で新規登録画面へ
```

### 作業カードタップ

```
1. カード全体がタップ領域
2. チェックボックス部分タップ → 完了/未完了切り替え
3. それ以外の部分タップ → 編集モーダルを開く
```

### 作業の並び替え

```
1. カードを長押し
2. カードが浮き上がる（elevation増加）
3. ドラッグで並び替え
4. ドロップで確定
```

### 日報作成

```
1. 「日報作成」ボタンをタップ
2. ローディング表示（ボタン内）
3. 日報データ生成
4. 日報プレビュー画面へ遷移
```

### 請求書作成

```
1. 「請求書」ボタンをタップ
2. 請求書編集画面へ遷移
3. 作業内容が明細に自動転記
```

## アニメーション

### 画面表示

```
0ms   : 背景表示
100ms : ヘッダースライドイン（上から）
200ms : 現場名セクションフェードイン
300ms : 作業カードが順にフェードイン（stagger 50ms）
400ms : フッターボタンスライドイン（下から）
```

### 作業追加

```
1. 「＋作業を追加」タップ
2. 新しいカードが上から折りたたまれながら展開
3. 同時にフォーカスが作業名入力へ移動
```

### 作業削除

```
1. 削除ボタンタップ
2. カードが右へスライドしながらフェードアウト
3. 下のカードが上へスライド
```

## 実装メモ

```typescript
// 自動保存（デバウンス）
const debouncedSave = useMemo(
  () => debounce((data: DraftData) => {
    saveDraft(data);
  }, 1000),
  []
);

useEffect(() => {
  if (hasUnsavedChanges) {
    debouncedSave(draftData);
  }
}, [draftData, hasUnsavedChanges]);

// 現場候補の検索
const searchSites = async (query: string) => {
  return database.get<Site>('sites')
    .query(
      Q.where('name', Q.like(`%${query}%`)),
      Q.sortBy('updated_at', Q.desc),
      Q.take(10)
    )
    .fetch();
};
```
