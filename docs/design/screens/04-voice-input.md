## インタラクション

### 録音開始

```
1. マイクボタンをタップ
2. マイク権限確認（初回のみ）
3. 触覚フィードバック（中程度）
4. 0.2秒でボタンが赤に変化
5. 波形ビジュアライザー開始
6. 時間カウント開始
```

### 録音停止

```
1. 停止ボタンをタップ
2. 触覚フィードバック（軽め）
3. 波形が停止
4. 0.3秒で完了画面にトランジション
```

### 自動停止

| 条件 | 動作 |
|------|------|
| 30秒経過 | 自動停止、完了画面へ |
| 3秒間無音 | 「音声が検出されません」表示（停止はしない） |

### 送信

```
1. 送信ボタンをタップ
2. ボタンがローディング状態に
3. 処理中画面へトランジション
4. API呼び出し（Whisper → GPT-4o）
5. 成功 → 下書き確認画面へ
6. 失敗 → エラー画面表示
```

## アニメーション詳細

### 待機 → 録音中

```
0ms   : ボタンの色が teal → red にクロスフェード
100ms : ボタンサイズが少し縮小（0.95）して戻る
200ms : パルスリングがボタン周囲に出現
300ms : 波形ビジュアライザーがフェードイン
```

### 録音中 → 完了

```
0ms   : パルスリングが停止
100ms : ボタンが縮小（scale: 0.8）
200ms : ボタンが完全に消えて再生ボタンがフェードイン
300ms : 下部ボタンが下からスライドイン
```

### 完了 → 処理中

```
0ms   : すべてのUIがフェードアウト開始
200ms : スピナーが中央にフェードイン
300ms : プログレスバーがフェードイン
400ms : テキストがフェードイン
```

## 実装メモ

```typescript
// 録音設定
const RECORDING_OPTIONS = {
  android: {
    extension: '.m4a',
    outputFormat: Audio.AndroidOutputFormat.MPEG_4,
    audioEncoder: Audio.AndroidAudioEncoder.AAC,
    sampleRate: 44100,
    numberOfChannels: 1,
    bitRate: 128000,
  },
  ios: {
    extension: '.m4a',
    audioQuality: Audio.IOSAudioQuality.HIGH,
    sampleRate: 44100,
    numberOfChannels: 1,
    bitRate: 128000,
  },
};

// 波形データ取得
const getWaveformData = (recording: Audio.Recording) => {
  // メータリングを有効化して音量レベルを取得
  recording.setOnRecordingStatusUpdate((status) => {
    if (status.metering) {
      const normalizedLevel = (status.metering + 160) / 160;
      updateWaveform(normalizedLevel);
    }
  });
};
```
