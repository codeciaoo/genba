## UI詳細

| 要素 | 仕様 |
|------|------|
| 色 | グラデーション: `--genba-navy-900` → `--genba-teal-900` |
| 方向 | 上から下への縦グラデーション |

### ロゴ

| 要素 | 仕様 |
|------|------|
| サイズ | 120px × 120px |
| 位置 | 画面中央、垂直方向は中央より少し上（40%位置） |

| 要素 | 仕様 |

| 要素 | 仕様 |

## 動作仕様

### 表示時間

| 状態 | 時間 |
|------|------|
| 最小表示時間 | 1.5秒（ブランディングのため） |
| 最大表示時間 | 5秒（タイムアウト） |

### 処理内容

1. **ローカルDB初期化** (WatermelonDB)
2. **認証状態確認** (Supabase Auth)
3. **ネットワーク状態確認**
4. **必要なら同期トリガー**

### 遷移ロジック

```
if (認証済み) {
  → ホーム画面 /(tabs)/
} else {
  → ログイン画面 /auth/login
}
```

---

## アニメーション

### 起動時

```
0ms    : 画面表示（背景グラデーション）
200ms  : ロゴがフェードイン + 少し上からスライド
500ms  : アプリ名がフェードイン
800ms  : ローディングドットがアニメーション開始
```

### 遷移時

```
遷移開始 : ロゴが少し拡大（scale: 1.05）
+100ms   : 画面全体がフェードアウト
+300ms   : 次の画面へ
```

## 実装メモ

```typescript
// app/index.tsx
import { useEffect } from 'react';
import { router } from 'expo-router';
import { useAuth } from '@/hooks/useAuth';

export default function SplashScreen() {
  const { isAuthenticated, isLoading } = useAuth();

  useEffect(() => {
    const timer = setTimeout(() => {
      if (!isLoading) {
        router.replace(isAuthenticated ? '/(tabs)/' : '/auth/login');
      }
    }, 1500); // 最小表示時間

    return () => clearTimeout(timer);
  }, [isAuthenticated, isLoading]);

  return <SplashView />;
}
```
