## 各ファイルの構成

各画面詳細ファイルには以下のセクションが含まれます:

1. **基本情報** - パス、MVP優先度、目的
2. **ワイヤーフレーム** - ASCIIアートによるレイアウト
3. **UI詳細** - 各要素の詳細仕様（サイズ、色、フォント等）
4. **インタラクション** - ユーザー操作時の動作
5. **状態別表示** - 条件による表示の違い
6. **エラー処理** - エラー時の表示
7. **アニメーション** - 遷移やフィードバックのアニメーション
8. **アクセシビリティ** - a11y対応
9. **実装メモ** - TypeScriptコード例
