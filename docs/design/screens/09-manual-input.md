## インタラクション

### 現場名選択

```
1. 入力欄をタップ
2. キーボード表示 + 既存現場のドロップダウン
3. 入力開始で絞り込み
4. 候補をタップで選択
5. 「新しい現場を登録」で新規登録モーダルへ
```

### 作業追加

```
1. 「＋ 作業を追加」をタップ
2. 新しい作業入力欄がアニメーションで展開
3. フォーカスが自動で新しい作業名入力欄へ
```

### 作業削除

```
1. 作業カードを左スワイプ
2. 「削除」ボタン表示（赤背景）
3. タップで削除（2件目以降のみ削除可能）
```

### 保存

```
1. 「記録を保存」ボタンをタップ
2. バリデーション実行
3. 成功 → ローカルDBに保存 → 下書き確認画面へ遷移
4. 失敗 → エラー箇所をハイライト
```

## バリデーション

### 現場名

| ルール | エラーメッセージ |
|--------|----------------|
| 必須 | 「現場名を入力してください」 |
| 最大50文字 | 「現場名は50文字以内で入力してください」 |

### 作業内容

| ルール | エラーメッセージ |
|--------|----------------|
| 最低1件の作業名必須 | 「作業内容を1件以上入力してください」 |
| 作業名必須（各項目） | 「作業名を入力してください」 |
| 作業名最大100文字 | 「作業名は100文字以内で入力してください」 |

## オフライン対応

| 状態 | 動作 |
|------|------|
| オンライン | 通常通り保存、即時同期 |
| オフライン | ローカルDBに保存、オンライン復帰後に同期 |

### オフライン時の表示

```
┌─────────────────────────────────┐
│ ⚠ オフライン                    │  ← --genba-warning 背景
│ 入力内容は端末に保存されます     │
└─────────────────────────────────┘
```

## アニメーション

### 画面表示

```
0ms   : 背景表示
100ms : ヘッダースライドイン（上から）
200ms : フォームセクションが順にフェードイン
300ms : 保存ボタンスライドイン（下から）
```

### 作業追加

```
1. 「＋作業を追加」タップ
2. 新しいフォームが高さ0から展開（200ms）
3. 同時にフォーカス移動
```

### 作業削除

```
1. カードが右へスライド + フェードアウト（200ms）
2. 下のカードが上へスライド（150ms）
```

## 遷移

### 進入元

- 音声入力画面（認識失敗時）→ 「手動で入力する」ボタン

### 遷移先

- 保存成功 → 下書き確認画面 `/draft/[id]`
- 戻る → 前の画面（音声入力 or ホーム）

## 実装メモ

```typescript
// app/manual-input.tsx
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { z } from 'zod';

const schema = z.object({
  siteName: z.string().min(1, '現場名を入力してください').max(50),
  tasks: z.array(z.object({
    name: z.string().min(1, '作業名を入力してください').max(100),
    detail: z.string().max(500).optional(),
  })).min(1, '作業内容を1件以上入力してください'),
  memo: z.string().max(1000).optional(),
});

type FormData = z.infer<typeof schema>;

export default function ManualInputScreen() {
  const { control, handleSubmit, formState: { errors } } = useForm<FormData>({
    resolver: zodResolver(schema),
    defaultValues: {
      siteName: '',
      tasks: [{ name: '', detail: '' }],
      memo: '',
    },
  });

  const onSubmit = async (data: FormData) => {
    // ローカルDBに保存
    const draft = await database.write(async () => {
      return await database.get<WorkRecord>('work_records').create((record) => {
        record.siteName = data.siteName;
        record.tasks = data.tasks;
        record.memo = data.memo;
        record.status = 'draft';
        record.inputMethod = 'manual';
        record.createdAt = new Date();
      });
    });

    router.push(`/draft/${draft.id}`);
  };

  return (
    // ... UI実装
  );
}
```
