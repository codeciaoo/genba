# GENBA GEAR チーム管理画面（Web）

> このドキュメントはNext.js (App Router)で構築するWeb管理画面の画面一覧です。
> モバイルアプリについては [screens.md](./screens.md) を参照してください。

## 技術スタック

| レイヤー | 技術 | 理由 |
|---------|------|------|
| フレームワーク | Next.js 14 (App Router) | SSR対応、Server Actions、Vercelデプロイ |
| スタイリング | Tailwind CSS | モバイルアプリと統一 |
| 認証 | Supabase Auth | モバイルと共通基盤 |
| データ取得 | Server Actions + Supabase | シンプルなデータフロー |
| グラフ | Recharts | 軽量・シンプル |
| フォーム | React Hook Form + Zod | バリデーション |

## 1. 認証系画面

### 1.1 ログイン画面
- **パス**: `/login`
- **目的**: チーム管理者の認証
- **要素**:
  - メールアドレス入力
  - Magic Link送信ボタン
  - 「アプリをダウンロード」リンク（モバイルへ誘導）
- **遷移先**: Magic Link → ダッシュボード

**ワイヤーフレーム**:
```
┌─────────────────────────────────────┐
│                                     │
│         GENBA GEAR                  │
│         チーム管理画面               │
│                                     │
│  ┌─────────────────────────────┐   │
│  │ メールアドレス               │   │
│  └─────────────────────────────┘   │
│                                     │
│       [ログインリンクを送信]         │
│                                     │
│  ─────────────────────────────────  │
│                                     │
│     アプリをお持ちでない方は         │
│     App Store / Google Play へ      │
│                                     │
└─────────────────────────────────────┘
```

### 1.2 招待受諾画面
- **パス**: `/invite/[code]`
- **目的**: 招待されたメンバーのチーム参加
- **要素**:
  - チーム名表示
  - 招待者名表示
  - 「参加する」ボタン
  - 既存アカウントへのログイン誘導
- **遷移先**: 参加完了 → ダッシュボード

## 3. 管理機能

### 3.1 メンバー管理
- **パス**: `/members`
- **目的**: チームメンバーの管理
- **対象ロール**: オーナー / 管理者
- **要素**:
  - メンバー一覧テーブル（名前、ロール、最終ログイン）
  - 検索・フィルター
  - 「メンバー招待」ボタン
  - 各メンバーの操作（編集、削除）

**ワイヤーフレーム**:

  - 有効期限設定（デフォルト7日）

### 3.6 請求書管理

- **目的**: チーム全体の請求書管理
- **対象ロール**: オーナー / 管理者
- **要素**:
  - 請求書一覧テーブル
  - ステータス管理（下書き/送付済/入金済）
  - 顧客フィルター
  - 一括PDF出力

### 3.7 請求書詳細
- **パス**: `/invoices/[id]`
- **目的**: 個別請求書の詳細表示
- **要素**:

  - PDF出力

### 3.8 顧客マスタ
- **パス**: `/customers`
- **目的**: 共有顧客情報の管理
- **対象ロール**: オーナー / 管理者
- **要素**:
  - 顧客一覧テーブル
  - 検索
  - 新規顧客追加
  - 各顧客の編集・削除

### 3.9 顧客詳細
- **パス**: `/customers/[id]`
- **目的**: 顧客の作業履歴・請求履歴

  - 編集ボタン

## 4. 設定系

### 4.1 プラン・課金
- **パス**: `/billing`
- **目的**: サブスクリプション管理
- **対象ロール**: オーナーのみ

  - メンバー数 / 上限
  - 次回請求日

### 4.2 チーム設定
- **パス**: `/settings`
- **目的**: チーム全体の設定
- **対象ロール**: オーナーのみ
- **要素**:
  - チーム名変更
  - チームロゴアップロード
  - 通知設定（未提出アラートなど）
  - チーム削除（確認ダイアログ付き）

## 5. モーダル・オーバーレイ

### 5.1 確認ダイアログ
- **用途**: 削除確認、ステータス変更確認
- **要素**:
  - タイトル
  - メッセージ
  - 「キャンセル」「確定」ボタン

### 5.2 ローディング
- **用途**: データ取得中、処理中
- **要素**:
  - スピナー
  - 「読み込み中...」テキスト

### 5.3 トースト通知
- **用途**: 成功/エラーメッセージ
- **要素**:
  - アイコン（✅ / ❌）
  - メッセージテキスト
  - 自動消去（3秒）
