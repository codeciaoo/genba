## 1. 認証系画面

### 1.1 スプラッシュ画面
- **パス**: `/`
- **目的**: アプリ起動時のブランディング
- **要素**:
  - GENBA GEAR ロゴ
  - ローディングインジケーター
- **遷移先**: 認証状態により → ログイン or ホーム

### 1.2 ログイン画面
- **パス**: `/auth/login`
- **目的**: ユーザー認証
- **要素**:
  - 電話番号入力（日本形式）
  - SMS認証コード入力
  - 「ログイン」ボタン
  - 「新規登録はこちら」リンク
- **遷移先**: SMS送信後 → OTP入力 → ホーム

### 1.3 新規登録画面
- **パス**: `/auth/register`
- **目的**: 新規ユーザー作成
- **要素**:
  - 屋号入力
  - 代表者名入力
  - 電話番号入力
  - 「登録する」ボタン
- **遷移先**: 登録完了 → 初期設定 or ホーム

### 1.4 初期設定画面
- **パス**: `/auth/onboarding`
- **目的**: 最低限の事業者情報入力
- **要素**:
  - 住所入力（任意）
  - インボイス登録番号（任意）
  - 振込先口座（任意）
  - 「あとで設定」「完了」ボタン
- **遷移先**: ホーム

## 2. メインタブ画面

### 2.1 ホーム画面（今日の現場）
- **パス**: `/(tabs)/`
- **目的**: 今日の作業状況一覧
- **要素**:
  - 日付表示（今日）
  - オフラインインジケーター（圏外時）
  - 今日の作業記録リスト
  - 中央下部: **音声入力ボタン（メイン）**
  - 未同期件数バッジ
- **遷移先**:
  - 音声ボタン → 音声入力画面
  - 作業記録タップ → 下書き詳細

### 2.2 日報一覧画面
- **パス**: `/(tabs)/reports`
- **目的**: 過去の日報閲覧・検索
- **要素**:
  - 月別カレンダービュー / リストビュー切替
  - 日報カード一覧（日付、現場名、ステータス）
  - 検索バー（音声検索対応）
  - フィルター（ステータス: 下書き/確定/送信済）
- **遷移先**: 日報タップ → 日報詳細

### 2.3 顧客・現場一覧画面
- **パス**: `/(tabs)/sites`
- **目的**: 顧客カルテ管理
- **要素**:
  - 現場/顧客カード一覧
  - 検索バー（音声検索対応）
  - 「＋新規現場」ボタン
  - 最近の現場セクション
- **遷移先**:
  - 現場タップ → 現場詳細
  - 新規 → 現場登録

### 2.4 設定画面
- **パス**: `/(tabs)/settings`
- **目的**: アプリ・事業者設定
- **要素**:
  - 事業者情報（屋号、住所、登録番号）
  - 振込先口座
  - 品目テンプレート管理
  - 通知設定
  - データ同期状態
  - ログアウト
  - バージョン情報
- **遷移先**: 各設定項目 → 個別設定画面

## 3. 作成フロー画面

### 3.1 音声入力画面
- **パス**: `/voice`
- **目的**: 音声録音・送信
- **要素**:
  - **大きなマイクボタン（画面中央）**
  - 録音時間表示
  - 波形ビジュアライザー
  - 「キャンセル」ボタン
  - 録音完了後: 「聞き直す」「送信」ボタン
- **状態**:
  - 待機中（タップで録音開始）
  - 録音中（赤く点滅）
  - 処理中（スピナー）
- **遷移先**: 送信完了 → 下書き確認

### 3.2 下書き確認画面
- **パス**: `/draft/[id]`
- **目的**: AI抽出結果の確認・編集
- **要素**:
  - 現場名（編集可）
  - 作業内容リスト（編集可）
  - 使用材料リスト（編集可）
  - 追加作業（ハイライト表示）
  - 備考・メモ（編集可）
  - 元の音声再生ボタン
  - 「日報を作成」「請求書を作成」ボタン
- **遷移先**:
  - 日報作成 → 日報プレビュー
  - 請求書作成 → 請求書編集

### 3.3 日報プレビュー画面
- **パス**: `/report/preview/[id]`
- **目的**: 生成された日報の確認
- **要素**:
  - 日報プレビュー（実際のPDFレイアウト）
  - 「確認用」透かし
  - 「編集」「確定」「PDFで保存」ボタン
- **遷移先**:
  - 編集 → 下書き確認
  - 確定 → 日報詳細
  - PDF保存 → シェアシート

### 3.4 請求書編集画面
- **パス**: `/invoice/edit/[id]`
- **目的**: 請求書の編集・金額確認
- **要素**:
  - 請求先情報
  - 明細テーブル（品目、数量、単価、金額）
  - 小計 / 消費税 / 合計
  - 発行日 / 支払期限
  - 振込先情報
  - 「プレビュー」「下書き保存」ボタン
- **遷移先**: プレビュー → 請求書プレビュー

### 3.5 請求書プレビュー画面
- **パス**: `/invoice/preview/[id]`
- **目的**: 請求書の最終確認
- **要素**:
  - 請求書プレビュー（インボイス対応レイアウト）
  - 「編集」「確定」「PDFで送信」ボタン
- **遷移先**:
  - 編集 → 請求書編集
  - 確定 → 請求書詳細
  - PDF送信 → シェアシート / メール選択

### 3.6 手動作業記録入力画面
- **パス**: `/manual-input`
- **MVP**: P1（音声認識失敗時のフォールバック）
- **目的**: 音声入力が使えない場合の手動入力フォーム
- **要素**:
  - 現場名入力（コンボボックス）
  - 作業内容リスト（追加・編集・削除可能）
  - 備考・メモ（任意）
  - 「記録を保存」ボタン
- **遷移先**:
  - 保存成功 → 下書き確認画面
  - 戻る → 前の画面（音声入力 or ホーム）

## 4. 詳細・編集画面

### 4.1 日報詳細画面
- **パス**: `/report/[id]`
- **目的**: 確定済み日報の閲覧
- **要素**:
  - 日報全文表示
  - ステータス（下書き/確定/送信済）
  - 「PDF出力」「共有」ボタン
  - 「編集」ボタン（下書きのみ）
  - 関連する請求書へのリンク
- **遷移先**: PDF出力 → シェアシート

### 4.2 請求書詳細画面
- **パス**: `/invoice/[id]`
- **目的**: 請求書の閲覧・ステータス管理
- **要素**:
  - 請求書全文表示
  - ステータス（下書き/送信済/入金済）
  - 「PDF出力」「共有」ボタン
  - 「入金済みにする」ボタン
  - 元の日報へのリンク
- **遷移先**: ステータス変更 → 確認ダイアログ

### 4.3 現場詳細画面
- **パス**: `/site/[id]`
- **目的**: 顧客カルテ閲覧
- **要素**:
  - 現場名 / 顧客名
  - 住所（地図リンク）
  - 連絡先
  - 過去の作業履歴リスト
  - 過去の請求書リスト
  - AI要約（過去の作業まとめ）
  - 「編集」「新規作業記録」ボタン
- **遷移先**:
  - 作業履歴 → 日報詳細
  - 新規作業 → 音声入力（現場紐付き）

### 4.4 現場登録・編集画面
- **パス**: `/site/edit/[id?]`
- **目的**: 現場・顧客情報の登録/編集
- **要素**:
  - 現場名入力
  - 顧客名入力
  - 顧客種別（個人/法人）
  - 住所入力
  - 連絡先入力
  - 備考・メモ
  - 「保存」ボタン
- **遷移先**: 保存 → 現場詳細

## 5. 設定系画面

### 5.1 事業者情報編集画面
- **パス**: `/settings/business`
- **目的**: 事業者情報の編集
- **要素**:
  - 屋号
  - 代表者名
  - 郵便番号 / 住所
  - 電話番号
  - メールアドレス
  - インボイス登録番号
  - 「保存」ボタン

### 5.2 振込先口座編集画面
- **パス**: `/settings/bank`
- **目的**: 振込先情報の編集
- **要素**:
  - 銀行名
  - 支店名
  - 口座種別（普通/当座）
  - 口座番号
  - 口座名義（カタカナ）
  - 「保存」ボタン

### 5.3 品目テンプレート一覧画面
- **パス**: `/settings/templates`
- **目的**: よく使う品目の管理
- **要素**:
  - 品目カード一覧（名前、単価、単位）
  - 「＋新規品目」ボタン
  - ドラッグで並び替え
- **遷移先**: 品目タップ → 品目編集

### 5.4 品目テンプレート編集画面
- **パス**: `/settings/templates/[id?]`
- **目的**: 品目の登録/編集
- **要素**:
  - 品目名
  - 単位（式、個、m、時間など）
  - 単価（税抜）
  - 税率（10% / 8%）
  - カテゴリ
  - 音声認識キーワード
  - 「保存」「削除」ボタン

## 6. モーダル・オーバーレイ

### 6.1 オフラインバナー
- **表示条件**: ネットワーク未接続時
- **要素**:
  - 「オフラインモード」テキスト
  - 未同期件数

### 6.2 同期中インジケーター
- **表示条件**: バックグラウンド同期中
- **要素**:
  - スピナー
  - 「同期中...」テキスト

### 6.3 確認ダイアログ
- **用途**: 削除確認、ステータス変更確認
- **要素**:
  - メッセージ
  - 「キャンセル」「確定」ボタン

### 6.4 シェアシート
- **用途**: PDF共有、メール送信
- **要素**:
  - OSネイティブのシェアシート
