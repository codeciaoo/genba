## 機能詳細

### A-1. 騒音耐性AIボイス入力

**目的**: 騒音の多い建設現場でも、喋るだけで正確にテキスト化

**仕様**:
- 録音時間: 3〜30秒
- 騒音フィルタリング: OpenAI Whisperカスタムモデル（建設現場騒音学習済み）
- 構造化抽出: GPT-4o-miniで作業内容・現場名・時間を自動抽出
- オフライン対応: 録音はローカル保存、オンライン時に処理

**UI要件**:
- マイクボタン: 画面中央、120×120px以上
- 録音中インジケーター: 波形アニメーション
- 1タップで開始、もう1タップで終了

### A-2. 簡易日報生成

**目的**: 音声入力から日報下書きを自動生成

**仕様**:
- 入力: 音声テキスト + GPS位置 + 天気情報
- 出力: 構造化された日報データ（日時、現場、作業内容、備考）
- PDF出力: 法規準拠フォーマット
- 編集: 生成後に手動修正可能

**自動付与データ**:
- 現在地（GPS）
- 天気・気温（OpenWeatherMap API）
- 作業開始/終了時刻

### A-3. 請求書自動生成

**目的**: 日報から請求書下書きを自動生成し、月末作業を削減

**仕様**:
- 日報からの転記: 作業内容・日時を自動反映
- インボイス制度対応: 登録番号、税率区分、消費税計算
- PDF出力: A4縦、印刷対応フォーマット
- 顧客情報連携: 顧客カルテから宛先自動入力

### A-4. オフライン動作

**目的**: 圏外現場でも業務が止まらない

**仕様**:
- ローカルDB: WatermelonDB（SQLiteベース）
- 全データローカル保存: 日報、請求書、顧客情報
- 同期: オンライン復帰時にSupabaseへ自動同期
- 競合解決: 最終更新タイムスタンプ優先
