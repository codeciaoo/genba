# GENBA GEAR - 開発イシュー管理

## プロジェクト概要

建設現場職人向けAIポケット事務員アプリ「GENBA GEAR」の開発イシュー管理

**コンセプト**: AIがあなたのポケット事務員に。喋るだけで日報・請求書が完成！

### ターゲット

- **個人プラン（無料）**: 個人事業主・一人親方
- **チームプラン（月額¥3,000）**: 中規模チーム（5-50人規模）

## 技術スタック

| レイヤー | 技術 |
|---------|------|
| モバイルアプリ | React Native (Expo) |
| ローカルDB | WatermelonDB |
| バックエンド | Supabase |
| AI処理 | OpenAI (Whisper + GPT-4o-mini) |
| GPS/天気 | Expo Location + OpenWeatherMap |
| LP | Astro + Tailwind CSS |

## 機能一覧

### A. コア機能（MVP必須）

| 機能 | 詳細 | 個人 | チーム |
|------|------|------|--------|
| 騒音耐性AIボイス入力 | マイク1タップ、3-30秒、騒音フィルタリング | ✅ | ✅共有 |
| 簡易日報生成 | GPS+天気統合、法規準拠PDF | ✅ | ✅集約 |
| 請求書自動生成 | 日報から請求書下書き、インボイス対応、PDF出力 | ✅ | ✅共有 |

### B. 連携機能（v1.1）

| 機能 | 詳細 | 個人 | チーム |
|------|------|------|--------|
| GPS自動通知 | 現場半径500m検知でSMS自動送信 | 施主通知 | チーム共有 |
| 軽量顧客カルテ | 声検索で過去データ表示、AI要約 | ローカル | アクセス権限 |
| 熱中症/安全アラート | 天気+GPSで高温警報通知 | 単独 | 一括通知 |

### C. 拡張機能（v2）

| 機能 | 詳細 | 対象 |
|------|------|------|
| チームタスク割り当て | 声入力でタスク共有 | チームのみ |
| 即時スマホ決済 | Stripe連携、QR決済 | 個人/チーム |
| 簡易資金化 | ファクタリング申請連携 | 個人/チーム |
